Spelunky 2 4:3 Patcher

Patches Spel2.exe for native 4:3 aspect ratio and Android/ARM64 startup compatibility, in one self-contained file.

Everything runs locally in your browser. Your Spel2.exe is never uploaded and never leaves this device.

1 Choose your game file

Select Spel2.exe from your Spelunky 2 game directory:

  • DroidDeck/root/.local/share/Steam/steamapps/common/Spelunky 2/Spel2.exe
  • Windows, Linux, Steam Deck, GameNativeSpelunky 2/Spel2.exe

Can't select the file on Android? In the file picker's menu, switch to “All files” or “Browse”.

Before you use it

  1. Keep a backup of your original Spel2.exe.
  2. Put the patched file in the game folder, replacing the original. mod_43aspect.ini appears next to it on first launch. Its view = expand keeps the full 16:9 width and shows more of the level above and below; set view = crop to keep the 16:9 height and cut off the sides instead, or a number from 0 to 100 for anything in between.
  3. Do not also install the mod's discord_game_sdk.dll. If both are there, the dll stays idle.
  4. Steam “Verify integrity of game files” will undo the patch.
What does the patch do?

1. Android fix. The game reserves 5 blocks of 32 MiB at random address hints between 0x701 and 0x7FF shifted left 32 bits, which is above 7 TiB, and retries forever when that fails. Android / ARM64 kernels with a 39-bit address space (512 GiB) can never satisfy that, so the game hangs. The patch changes two single bytes so hints stay at 0x01 to 0x7F shifted left 32 bits (below 512 GiB):

  • MOV RBX, 0x7017F800000 becomes MOV RBX, 0x17F800000
  • AND ECX, 0xFE becomes AND ECX, 0x7E

The page only patches when both spots are found exactly once, both stock or both already patched (by this page's older version or GabrielGabriel197's patcher). Otherwise it changes nothing.

2. Native 4:3. The page adds the mod to Spel2.exe as a new section and runs it from the exe's entry point before the game starts. It is the same code as discord_game_sdk.dll from the release (sha256 ), built from the source. It patches the projection, viewport and 2D UI for 4:3 in memory and restores the audio that Android leaves muted. Settings live in mod_43aspect.ini.

On Windows PC? You can skip this page: drop discord_game_sdk.dll from the latest release into the game folder instead.
