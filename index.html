Before you use it
  • Keep a backup of your original Spel2.exe.
  • Put the patched file in the game folder, replacing the original.
  • Steam "Verify integrity of game files" will undo the patch.

Privacy: the file never leaves your device. Everything runs in this page, with no uploads and no external requests.

What does the patch do?

The game reserves 5 blocks of 32 MiB at random address hints between 0x701 and 0x7FF shifted left 32 bits, which is above 7 TiB, and retries forever when that fails. Android / ARM64 kernels with a 39-bit address space (512 GiB) can never satisfy that, so the game hangs. The patch changes two single bytes so hints stay at 0x01 to 0x7F shifted left 32 bits (below 512 GiB):

  • MOV RBX, 0x7017F800000 becomes MOV RBX, 0x17F800000
  • AND ECX, 0xFE becomes AND ECX, 0x7E

The page only patches when both spots are found exactly once in their stock form. Otherwise it changes nothing.
